# Furchain Registry

The canonical character registry for the Furchain Protocol v1.0.

## Purpose

The registry is the discovery layer for Furchain characters. It maps character UUIDs to their GitHub repository locations, enabling cross-user discovery via `furchain search` and `@uuid` resolution.

## Directory Structure

```
v1/
├── by-id/                    # Source of truth (one JSON file per character)
│   └── <uuid>.json
└── derived/                  # CI-generated indexes (do not edit manually)
    ├── by-name/
    │   └── <name>.json       # Array of entries matching this name
    └── by-owner/
        └── <owner>.json      # Array of entries owned by this user
```

- `by-id/` is the source of truth. Each file is a single registry entry.
- `derived/` indexes are regenerated by CI on every merge to `main`. Do not edit them manually.

## Registry Entry Schema

Each `by-id/<uuid>.json` file:

```json
{
  "id": "<UUIDv7>",
  "name": "<character-name>",
  "display": "<Display Name>",
  "owner": "<github-username>",
  "repo": "<repo-name>",
  "path": "characters/<name>",
  "fingerprint": "sha256:<64-hex-chars>",
  "registered": "<ISO-8601>"
}
```

## How to Register

Use the Furchain CLI:

```bash
furchain register --submit
```

This forks the registry, creates a branch with your character's entry, and opens a PR. The CI workflow validates the entry before merge.

## Manual Registration

1. Fork this repository
2. Create `v1/by-id/<your-character-uuid>.json` with the schema above
3. Open a PR to `FurchainLabs/registry`
4. CI will validate: ID uniqueness, repo accessibility, fingerprint match, schema compliance

## Validation Rules (Section 20.3)

1. ID must be unique (no existing entry with same UUID)
2. GitHub owner must exist
3. Repository must be accessible and public
4. `furchain.json` in the repo must contain the character
5. `keys.json` signing key fingerprint must match the registry entry
6. Entry must pass JSON Schema validation

## HTTP Access

The registry is served as static JSON via GitHub Pages:

```
https://furchainlabs.github.io/registry/v1/by-id/<uuid>.json
https://furchainlabs.github.io/registry/v1/derived/by-name/<name>.json
https://furchainlabs.github.io/registry/v1/derived/by-owner/<owner>.json
```
